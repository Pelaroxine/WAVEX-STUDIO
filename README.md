# WAVEX-STUDIO 🎛️

**WAVEX-STUDIO** is a lightweight, web-based Digital Audio Workstation (DAW) and mobile studio mixer designed for real-time audio processing, multi-track mixing, and sound manipulation.

---

## 🚀 Key Features

- **Multi-Track Mixer Engine:** Full volume control, mute, and solo toggle across individual channels.
- **3-Band Parametric EQ:** Low, Mid, and High frequency adjustments (-12dB to +12dB) per track.
- **Real-Time Synthesis:** Built-in Web Audio API engine for live synth loops and drum patterns.
- **Visual Peak Metering:** Dynamic VU meters tracking live audio output per channel and on master.
- **Master Bus:** Global fader controls and master EQ processing.

---

## 🛠️ Tech Stack

- **Frontend UI:** HTML5, CSS3, JavaScript (ES6+)
- **Audio Processing Engine:** Web Audio API
